# web_lab3 — Personal Portfolio II

CS344: Web Engineering — Lab 3: HTML Advanced

## Structure
```
portfolio/
├── index.html
├── hobbies.html
├── contact.html
├── gallery.html
├── skills.html
├── css/
│   └── style.css
├── images/
│   ├── personal.jpeg
│   ├── photo1.jpg
│   ├── photo2.jpg
│   ├── photo3.jpg
│   ├── photo4.jpg
│   ├── photo5.jpg
│   └── photo6.jpg
└── README.md
```

All CSS lives in `css/style.css` (no inline styles). The nav bar, the
home page photo/about row, the skills columns, and the image gallery are
all laid out with `float` + `clear` — no JavaScript, no CSS frameworks.
